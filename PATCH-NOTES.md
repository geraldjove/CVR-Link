# CVR Link / CVRFlatscreen 0.2.3

16 September 2026

## What's new

- **FOV slider:** set your view from 80 to 120 degrees in CVR Link's
  UI Settings. It starts at 80. Click Save settings to apply it in play.
- **Automatic bolt cycling:** bolt-action guns cycle after a shot. Release
  fire and click again for the next shot. R still reloads. No extra ammo is added.
- **Player list removed:** Windows and Quest menus no longer show the
  flatscreen player list. The bottom-center CVRFlatscreen button still opens
  the popup with downloads, Discord, and author details.

## How to update

**Windows:** close Contractors and CVR Link. Download
[CVRLink.exe](https://github.com/geraldjove/CVR-Link/releases/tag/v0.2.3),
open it, and click **Install CVR Link**. Update CVRFlatscreen in the game too.
Use the updated desktop shortcut. Your saved settings stay in place.

**Quest:** update CVRFlatscreen in Contractors, then restart the game.
You do not need the Windows app. If the old menu stays after updating,
reinstall this loadout and restart Contractors.

## Test status

FOV and automatic bolt cycling are confirmed in play. Code checks and
chambering checks on six stock rifles pass. Windows, Quest, and server
packages pass build checks. More guns, maps, menus, death/rejoin, mixed
PC/Quest matches, and dedicated servers still need play tests.

**Open issue:** multiplayer has been reported as locked with Experimental
start. This is still being checked. Removing the player list does not fix
online sign-in or change your name on the game's scoreboard.

Quest uses VR controllers. Gadget hands stay hidden in flatscreen.
Loose-round guns do not yet have keyboard reload support.
